# Equestria Unity Log

Маленькое окно, которое показывает, как дела у Unity: какой шейдер компилируется
сейчас и последние строки лога. Unity не трогает — только читает файл.

## Запуск
    python3 logwatch.py                  # спросит, какой лог читать
    python3 logwatch.py /путь/Editor.log # без вопроса

Для запуска нужны PyQt6 и `equestria-qt-kit` версии 1.5 или новее.
В репозитории приложение использует соседний каталог `../equestria-qt-kit`.
Язык можно сменить в верхней части окна. Выбор сохраняется между запусками.

## Установка в Arch Linux

Из каталога приложения выполните `makepkg -si`. После установки откройте
**Equestria Unity Log** из меню приложений или выполните
`equestria-unity-log /путь/Editor.log`.

## Где лежит лог Unity на Linux
- Редактор: `~/.config/unity3d/Editor.log`
- Свой лог билда: тот файл, куда вы его пишете (`-logFile путь`)

## Если шейдеры не определяются
Откройте `logcore.py` — вверху есть `SHADER_RX`. Это «по каким словам искать
строки про шейдеры». Посмотрите в вашем логе, как они выглядят, и поправьте слова.

## Почему не тормозит
Файл целиком не читается: берутся последние 256 КБ, дальше — только то, что
дописалось. В памяти остаются последние 2000 прочитанных строк (до 600 символов каждая).


## Поиск и фильтры

Включите «Фильтр», выберите категорию и при необходимости введите часть текста.
Поиск по подстроке работает без учёта регистра в пределах сохранённой истории.
Снятие галочки сразу показывает все категории и временно отключает текстовый поиск.
Повторное включение возвращает тот же запрос. Поле «Строк» задаёт количество последних
совпадений от 1 до 200 (по умолчанию 5). Режим, галочка и количество сохраняются между запусками.
