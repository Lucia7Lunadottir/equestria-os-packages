# Equestria clock

`equestria_clock.py` — только точка входа. Реализация находится в `equestria_clock_app/`.

schedule — расписание; settings — хранение; sound — воспроизведение; alarms / timer / stopwatch — независимые режимы.

`window` связывает компоненты и обрабатывает действия пользователя. `app` запускает Qt.
`style` управляет темой; `paths` задаёт пути; `localization` подключает общий каталог.
Зависимости указаны явно, без wildcard-импортов. `compat` сохраняет прежние импорты
для встраивания и внешних потребителей; внутри пакета он не используется.
Классы моделей, хранилищ, стратегий системного взаимодействия и виджетов сохраняют
отдельные обязанности. Новые форматы переводов не требуют изменения этих классов.

Каждый файл `locales/<код>.json` — отдельный язык. Название задаётся необязательным
`_language_name`; без него используется имя файла. Добавленный файл обнаруживается
при следующем запуске, выбранный язык применяется сразу и сохраняется. Подписи
обновляются на существующих объектах, без пересоздания страниц и пользовательского ввода.

Пакет устанавливает Python-модули в `/usr/lib/equestria-clock`, переводы — в
`/usr/share/equestria-clock/locales`. При запуске из исходников используются соседние файлы.
