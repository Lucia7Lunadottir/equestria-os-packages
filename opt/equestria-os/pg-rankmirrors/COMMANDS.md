# pg-rankmirrors — команды и действия GUI

Тонкий Qt-фронт (`main.py`) над одним bash-скриптом `/usr/bin/pg-rankmirrors-backend` (`pg-rankmirrors-backend`), который делает всю реальную работу. Все привилегированные подкоманды сами проверяют `[ "$EUID" -ne 0 ]` и отказывают без root — GUI зовёт их только через `pkexec`.

## Подкоманды `pg-rankmirrors-backend`

| Подкоманда | Функция в скрипте | Кто вызывает | Root? | Что делает |
|---|---|---|---|---|
| `list-countries` | `ListCountries()`, строка 37 | При открытии окна | Нет | `reflector --list-countries`, парсит в JSON-список код/имя страны. |
| `current` | — | При открытии + после применения | Нет | `grep "^Server" /etc/pacman.d/mirrorlist \| head -10`. |
| `rank <коды через запятую>` | `RankMirrors()`, строка 75 | Кнопка «Применить» | **Да** | См. разбор ниже. |
| `restore` | `RestoreBackup()`, строка 105 | Кнопка «Восстановить» | **Да** | `cp /etc/pacman.d/mirrorlist.bak /etc/pacman.d/mirrorlist`. |
| `auto-rank` | — | pacman-хук и systemd-таймер | Да (уже в этих контекстах) | То же самое, что `rank`, со странами из сохранённого конфига. |

## `reflector` — объяснение флагов (`RankMirrors()`, `pg-rankmirrors-backend:89-94`)

```bash
LANG=C reflector --country <A> --country <B> ... --protocol https --sort rate --latest 20 --save /etc/pacman.d/mirrorlist
```

> **`reflector`** — официальная утилита сообщества Arch Linux для подбора и ранжирования зеркал пакетов. Список серверов, с которых `pacman` скачивает пакеты (`/etc/pacman.d/mirrorlist`), не привязан к географии автоматически — Arch отдаёт это на откуп пользователю/дистрибутиву, и `reflector` — стандартный способ выбрать быстрые.

* `LANG=C` — форсирует английскую локаль для самой команды, чтобы её текстовый вывод (используемый скриптом для парсинга) не менялся в зависимости от языка системы.
* `--country <код>` (можно указывать несколько раз, скрипт собирает по одному на каждую выбранную страну) — ограничить список зеркал только серверами физически расположенными в этих странах (обычно чем ближе географически — тем ниже задержка).
* `--protocol https` — использовать только зеркала, отдающие пакеты по HTTPS (не HTTP/rsync/FTP) — шифрованное соединение, защита от подмены пакетов в пути посторонним на сети между пользователем и зеркалом.
* `--sort rate` — из отобранных по стране/протоколу зеркал отсортировать по реально измеренной скорости скачивания (`reflector` сам делает тестовое скачивание с каждого кандидата), а не по алфавиту/случайности.
* `--latest 20` — брать в рассмотрение только 20 зеркал с самым недавним временем последней синхронизации (устаревшее зеркало может быстро отдавать данные, но не иметь свежих пакетов — этот флаг исключает такие).
* `--save /etc/pacman.d/mirrorlist` — записать итоговый отсортированный список прямо в файл, который использует `pacman` (без этого флага `reflector` просто напечатал бы список в stdout, ничего не изменив).

## Безопасность (`RankMirrors()`, `pg-rankmirrors-backend:81, 96-102`)

* Перед запуском `reflector` — `cp /etc/pacman.d/mirrorlist /etc/pacman.d/mirrorlist.bak` — резервная копия ДО любых изменений.
* Если `reflector` завершился с ошибкой (например, нет сети или ни один сервер не ответил) — **автоматически** `cp /etc/pacman.d/mirrorlist.bak /etc/pacman.d/mirrorlist`, восстанавливая рабочий список зеркал, вместо того чтобы оставить систему с пустым/повреждённым файлом — иначе следующий `pacman -Syu` вообще не смог бы ничего скачать.

## Автоматика вне GUI

* **`pg-rankmirrors.hook`** — pacman-хук (тот же встроенный в pacman механизм, что использует `equestria-save-point`, см. его `COMMANDS.md` за подробным объяснением), срабатывает `PostTransaction` при обновлении пакета `pacman-mirrorlist` (то есть когда сам Arch выпускает обновлённый эталонный список зеркал) — запускает `pg-rankmirrors-backend auto-rank`.
* **`pg-rankmirrors.timer`** (`OnCalendar=weekly`, `RandomizedDelaySec=2h` — случайная задержка до 2 часов от запланированного времени, чтобы не все системы в мире синхронно долбили зеркала ровно в момент времени "weekly") → **`pg-rankmirrors.service`** → тот же `auto-rank`.
* Включение/выключение автообновления в GUI (переключатель) → `pkexec pg-rankmirrors-backend <включить/выключить>` (управляет юнитом `pg-rankmirrors.timer` через systemd), состояние читается через `systemctl is-enabled pg-rankmirrors.timer` (без root — просто чтение статуса юнита, не требует привилегий).

## Прочее

* Если `reflector` не установлен — все команды возвращают `{"error":"reflector is not installed"}` в JSON, GUI показывает это как обычное сообщение, не падает.
* `/etc/pacman.d/mirrorlist.bak` — единственный бэкап (перезаписывается при каждом `rank`), не версионируется по времени в отличие от, например, `equestria-os-save-point`.
