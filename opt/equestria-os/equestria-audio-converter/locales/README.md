# Локализация

Каждый `*.json` в этой папке — отдельный язык в списке приложения.
Имя файла — код локали, например `it.json` или `pt_BR.json`. Список кодов
в Python отсутствует. После добавления файла запустите приложение заново.

Формат — объект «смысловой ключ (`модуль.смысл`): перевод», образец — `en.json`.
Необязательный ключ `_language_name` задаёт название языка в списке;
без него показывается код из имени файла. Сохраняйте подстановки `{}`,
`{name}` и параметры фильтров файлов в переводах.

Недостающая или пустая строка берётся из `en.json`, затем показывается
сам ключ. Повреждённые файлы пропускаются с предупреждением.
Выбор в списке сразу применяется к интерфейсу и сохраняется для следующих запусков.
Без сохранённого выбора используются EQUESTRIA_LANG, LANGUAGE, LC_ALL,
LC_MESSAGES, LANG; региональная локаль сначала ищется целиком, затем
по базовому коду. Неизвестные коды допустимы, если существует их JSON-файл.

При установке файлы находятся в `/usr/share/equestria-audio-converter/locales`.
Пользовательские переводы можно добавлять в
`$XDG_DATA_HOME/equestria-audio-converter/locales`
(по умолчанию `~/.local/share/equestria-audio-converter/locales`).
Они имеют приоритет над переводами приложения с тем же именем файла.
