# Переводы

Каждый файл `<код>.json` добавляет язык в список без изменения Python.
Формат: смысловой ключ (`модуль.смысл`, например `window.theme`) → перевод;
образец для переводчика — `en.json`. Необязательный `_language_name`
задаёт название языка; иначе показывается код файла. Сохраняйте подстановки
`{}` и `{name}`. Недостающие строки берутся из английского, затем показывается сам ключ. Невалидные файлы пропускаются с предупреждением.

Язык меняется сразу без пересоздания страниц. Новые файлы обнаруживаются
при запуске. Пользовательские файлы: `~/.local/share/equestria-calendar/locales/`
(или `$XDG_DATA_HOME/equestria-calendar/locales/`). Они имеют приоритет над комплектными.
