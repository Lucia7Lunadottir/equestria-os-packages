# Локализация

Добавьте `<код>.json` в эту папку — при следующем запуске язык появится
в списке автоматически. `_language_name` задаёт название языка; без него
отображается код файла. Скопируйте структуру `en.json` и переведите значения,
сохраняя ключи и подстановки `{}`. Непереведённые строки берутся из английского.
Выбор языка применяется сразу и сохраняется. Новые языки не требуют правок Python.

Используется общий `equestria-qt-kit>=1.3`, как в остальных приложениях.
