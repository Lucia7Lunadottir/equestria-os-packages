# Переключение языка без пересоздания интерфейса

`live_i18n.Catalog(app_id, script_file)` загружает `locales/*.json` рядом
со скриптом и из каталогов данных XDG. Имя файла — код языка; списка
поддерживаемых кодов в Python нет. `_language_name` — необязательное
название для списка; без него `Catalog.language_name()` берёт родное название
языка у Qt (`QLocale.nativeLanguageName`), а для неизвестного кода — сам код. Невалидные JSON-файлы пропускаются с предупреждением.

`catalog.tr(key, *args)` по смысловому ключу (`модуль.смысл`) возвращает строку с сохранённым
ключом и аргументами. Передавайте её Qt через `live_i18n.call`:

```python
catalog = live_i18n.Catalog("my-app", __file__)
tr = catalog.tr
label = live_i18n.call(QLabel, tr("search.found", count))     # en.json: "Found: {}"
live_i18n.call(button.setText, tr("common.refresh"))
layout.addWidget(catalog.selector(window))
```

Привязка относится к конкретному свойству, а не ищет совпадающий текст
по всему окну. Переводятся подписи, подсказки, placeholder, действия меню
и элементы списков. Пользовательский ввод и itemData остаются прежними.
При обновлении блокируются сигналы соответствующего виджета, ссылки на
удалённые объекты не удерживаются. `format_text` сохраняет переводимые
части составной подписи. Для собственной отрисовки после переключения
нужно вызвать `update()`; `call(painter.drawText, ..., text)` разрешает
перевод в момент рисования.

Выбранный код сохраняется в `$XDG_CONFIG_HOME/<app_id>/language.json`.
Без выбора используются EQUESTRIA_LANG, LANGUAGE, LC_ALL, LC_MESSAGES,
LANG; отсутствующие строки берутся из английского, затем показывается сам ключ.
Стандартные элементы Qt получают QTranslator и QLocale выбранного языка.
Старый модуль `i18n` сохранён для приложений, которые ещё не мигрировали.

Калькулятор, календарь, диктофон и Unreal Launcher требуют пакет
`equestria-qt-kit>=1.3`. Из исходников они используют соседний каталог
библиотеки; при установке нужно обновлять библиотеку вместе с приложениями.

Проверки из каталога equestria-qt-kit:

```sh
PYTHONDONTWRITEBYTECODE=1 QT_QPA_PLATFORM=offscreen python3 -m unittest discover -s tests -p test_live_i18n.py
```

Тесты проверяют живые Qt-виджеты и отрисовку. Аудиоустройства диктофона,
сеть и WebEngine лаунчера подменены, чтобы не записывать звук и не запускать
внешние операции при проверке локализации.

Строки самой библиотеки (`kit.*`: подсказка «Язык», «Как в системе») лежат в
`equestria_kit/locales/` и через `Catalog.library_text()` следуют языку приложения.
